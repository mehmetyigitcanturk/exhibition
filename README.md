# Mehmet Yiğit Cantürk — kişisel site

Tek dosyalık statik site (index.html). Derleme gerekmez.

## GitHub Pages'te yayınlama

1. github.com'da yeni bir depo aç. Adı `KULLANICI_ADIN.github.io` olursa site doğrudan https://KULLANICI_ADIN.github.io adresinde açılır. Başka bir ad verirsen adres .../DEPO_ADI/ olur.
2. Bu klasörün içindeki tüm dosyaları (index.html, favicon.svg, favicon-192.png, favicon-512.png, .nojekyll) depoya yükle: "Add file" > "Upload files". .nojekyll gizli bir dosyadır, onu da eklemeyi unutma.
3. Depoda Settings > Pages bölümüne git. "Source" olarak "Deploy from a branch", dal olarak `main` ve klasör olarak `/ (root)` seç, Save'e bas.
4. Bir iki dakika sonra site yayında olur.

Mail adresi, metinler ve renkler index.html içinde. Değişiklik yapınca dosyayı depoda güncellemen yeterli.
